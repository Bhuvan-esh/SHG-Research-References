## How these references are intended to be used

Together, these sources provide context on the SHG ecosystem across six connected areas:

1. Institutional scale and digital infrastructure.
2. Production capacity and institutional procurement.
3. Pricing and financial sustainability.
4. Digital commerce and market access.
5. Working capital and collective tender participation.
6. Income generation and livelihood outcomes.

**Evidence note:** These links are supporting references, not proof that every programme or platform achieves the same outcomes in every location. Policy announcements, reported programme reach, operational examples, and independently evaluated outcomes should be distinguished when drawing conclusions.
